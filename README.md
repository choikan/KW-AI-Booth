## 배포

- **GitHub Pages**: 저장소 하나에 이 폴더 내용을 올리고 Settings → Pages에서 배포
- **Vercel**: 새 프로젝트로 이 폴더를 올리면 끝 (Framework: Other)

존별 QR은 `https://<주소>/coding/`처럼 각 경로로 만들면 돼요.

## 바꿔야 할 설정

| 파일 | 상수 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `raffle/index.html` | `ADMIN_PIN` | `2026` | 추첨함 운영진 메뉴 PIN |

PIN은 페이지 소스에 그대로 들어 있어요. 화면에서 실수로 여는 걸 막는 정도로만 생각해 주세요.

## 추첨함 데이터

- 응모 정보는 **응모를 받은 기기의 브라우저에만** 저장돼요 (서버로 보내지 않아요).
- 출구에서 기기 1대로 받는 걸 권장해요. 여러 대로 받았다면 각 기기에서 **CSV 저장** → 한 기기에서 **다른 기기 CSV 합치기**로 모은 뒤 추첨해요 (같은 전화번호는 자동 제외).
- 추첨·경품 지급이 끝나면 운영진 메뉴의 **전체 삭제**로 지워 주세요. 브라우저 방문 기록을 지워도 함께 사라지니 추첨 전에 CSV를 꼭 백업해 두세요.
